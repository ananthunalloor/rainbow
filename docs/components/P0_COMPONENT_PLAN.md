# Rainbow P0 Component Plan

P0 components are the minimum foundation for application forms and common interactions.

| Component | Tag | Status | Required acceptance |
|---|---|---|---|
| Button | `rainbow-button` | Implemented | keyboard, submit/reset, variants, disabled, events |
| Input | `rainbow-input` | Implemented | native validation, form association, errors, labels |
| Textarea | `rainbow-textarea` | Implemented | native validation, form association, labels |
| Select | `rainbow-select` | Implemented | native options, validation, form association |
| Checkbox | `rainbow-checkbox` | Implemented | checked state, required state, form association |
| Radio | `rainbow-radio` | Next | grouping and form association |
| Field group | `rainbow-field` | Next | label/help/error composition |
| Form | `rainbow-form` | Next | validation/event orchestration |
| Dialog | `rainbow-dialog` | Next | modal semantics, focus trap, Escape |
| Popover | `rainbow-popover` | Next | anchor positioning and dismissal |
| Alert | `rainbow-alert` | Next | status/alert semantics |
| Spinner | `rainbow-spinner` | Next | reduced-motion/accessibility |
